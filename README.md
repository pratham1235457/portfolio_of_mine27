* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3, Tailwind CSS
* **Backend:** Node.js, Express.js, Python (Flask / FastAPI)
* **Databases:** MongoDB, PostgreSQL, MySQL, Amazon DynamoDB
* **Cloud & DevOps:** AWS (EC2, S3, Lambda, API Gateway, Rekognition, IAM), Docker, Git, GitHub
